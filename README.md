# 🎨 Spectra Interior Designing

A modern AI-powered Interior Design web application built with **Lovable**, designed to help homeowners and businesses transform their spaces through professional interior design services.

**Live Demo:** https://spectra-interior-designing.lovable.app/

---

# 📖 Overview

Spectra Interior Designing is a responsive web application that showcases interior design services, completed projects, and allows prospective clients to easily book consultations.

The application combines a modern user interface with an intuitive booking experience, enabling clients to explore design portfolios and connect with professional designers.

# 🎯 User Flow

1. Visit the homepage.
2. Browse interior design services.
3. Explore completed projects.
4. Read client testimonials.
5. Book a consultation.
6. Receive confirmation.
7. Admin reviews the enquiry.
8. Project progresses through design stages.

# ⚙ Installation

Clone the repository:

```bash
git clone <repository-url>
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
